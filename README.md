Ecommerce Database SQL Analysis

Project Overview

This project analyzes ecommerce sales data using SQL Server to understand sales, profit, customers, products, categories, and regional performance.

Project Objective

The main objective is to use SQL queries to convert ecommerce data into useful business insights and demonstrate practical SQL and data analysis skills.
